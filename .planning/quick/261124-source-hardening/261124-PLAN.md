# Quick Task 261124: hardening source-side

## Objetivo

Aplicar no source as correções possíveis para as seis candidatas da auditoria, deixando apenas os fatos de provider/TLS/backup como `needs_validation`.

## Tasks

1. **Backend logs (TDD)**: criar `LogRedacao` com sanitização e truncamento; substituir logs brutos em IA, importação e webhook; testar CPF/CNPJ/cartão/telefone/e-mail/JWT/null/exceção.
2. **Backend headers/CORS (TDD)**: declarar CORS fechado e headers `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, HSTS e `cache-control` no `SecurityConfig`; testar via slice/helper sem Docker.
3. **Web convite (TDD)**: mover `conviteToken` da query para cookie httpOnly via `/convite/[token]`; `start` lê cookie, falha limpa ambos os cookies; callback continua enviando o token no corpo.
4. **Web headers (TDD)**: adicionar headers estáticos em `next.config.ts` sem CSP nonce e sem quebrar redirects OAuth.
5. **Web rate limit (TDD)**: singleton `globalThis`, janela de reinício, `Retry-After`, testes determinísticos.
6. **Web preview guard (TDD)**: helper server-only que valida `VERCEL_ENV=preview` contra `API_URL_PREVIEW`/`API_URL_PRODUCAO`; aplicar em BFF, callback, login, páginas e `lib/api`; documentar variáveis.

## Fora de escopo

Configurações de Vercel/Render, retenção de logs do provedor, backup/TLS e rotação de segredos: exigem ação do owner e permanecem documentadas como `needs_validation`.

## Gates

- `api/`: `.\mvnw.cmd "-Dspotless.check.skip=true" test`, `.\mvnw.cmd -q spotless:check`
- `web/`: `npm run lint`, `npx tsc --noEmit`, `npx playwright test e2e/frontend-fixes.spec.ts e2e/google-oauth.spec.ts e2e/auth-bff.spec.ts`, `npm run build`
