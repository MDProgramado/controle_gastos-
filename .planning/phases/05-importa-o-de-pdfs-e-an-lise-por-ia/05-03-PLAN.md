# 05-03 — Cliente IA de extração: cascata gratuita, backoff, JSON estrito, modeloUsado/degradado

**Wave:** 3 | **Depends on:** 05-02 | **Autonomous:** true | **Frontmatter status:** complete

## Objective

Estender `AiClient` para extração de PDFs: parametrizar `temperature`/`max_tokens` sem quebrar `completar(List<Map>)` (mockado nos testes existentes), generalizar gatilhos de falha (429/402/5xx/JSON inválido) com backoff exponencial 1,5→3→6 s (3 tentativas por modelo), honrar `Retry-After`, e expor `modeloUsado` + `degradado`. A extração faz **1 chamada de IA por documento** (protege a cota de 50 req/dia dos modelos `:free`). O caminho normal usa apenas modelos gratuitos (`31b:free → 26b-a4b-it:free → openrouter/free`); a reserva paga (`modelos-reserva`) continua como último recurso já existente.

## Requirements

IMP-04, IMP-06, IMP-07, IMP-08

## Decisions covered

D-15 (cascata gratuita existente, estender não reescrever), D-16 (reserva paga último recurso, não remover), D-17 (duas camadas), D-18 (gatilhos 429/402/5xx/JSON inválido), D-19 (1 chamada/documento; temperature=0.0, max_tokens=8000; reduzir para 4000 se rejeitado), D-20 (chat existente mantém defaults 0.4/800), D-21 (JSON estrito; parse remove cercas ```), D-22 (modeloUsado/degradado na resposta), D-23 (503 amigável via `ServicoIaIndisponivelException`)

## Threat Model

| Ameaça | Severidade | Mitigação |
|--------|------------|-----------|
| Modelo pago acionado sem intenção (cobrança acidental) | Alta | Teste de guarda: inspecionar corpo da requisição, falhar se aparecer id pago fora de `modelos-reserva`; 05-03-t4 |
| Cota `:free` esgotada (50 req/dia) derrubando importação | Média | 1 chamada/documento (D-19); reserva paga como último recurso (D-16); 503 amigável se tudo falhar (D-23) |
| `openrouter/free` devolvendo JSON inválido (modelo fraco) | Média | Gatilho "JSON inválido" avança a cascata; validação campo a campo; item rejeitado sem derrubar documento (D-21) |
| Prompt injection via texto do PDF no system/user message | Média | Prompt com delimitadores rígidos; instrução de "somente JSON, sem markdown"; resposta validada como JSON (05-04) |
