# 05-02 — Extração PDFBox, sanitização de dados sensíveis e classificação de documento

**Wave:** 2 | **Depends on:** 05-01 | **Autonomous:** true | **Frontmatter status:** complete

## Objective

Implementar extração de texto de PDF no backend com Apache PDFBox (sem OCR), sanitização (mascarar CPF/CNPJ/números de cartão) antes de qualquer envio à OpenRouter, e heurística de classificação do documento (fatura de cartão × extrato bancário). PDF sem texto extraível é reportado como `SEM_TEXTO` sem derrubar o lote.

## Requirements

IMP-02, IMP-03, IMP-04, IMP-14

## Decisions covered

D-04 (validação de arquivo: content-type + magic bytes + tamanho + quantidade), D-11 (PDFBox texto, sem OCR), D-12 (sem texto = aviso, lote continua), D-13 (sanitização obrigatória antes do envio), D-14 (PDF bruto não persistido)

## Threat Model

| Ameaça | Severidade | Mitigação |
|--------|------------|-----------|
| Arquivo não-PDF disfarçado (extensão .pdf com conteúdo outro) | Alta | Validar magic bytes `%PDF` no início do arquivo + content-type; rejeitar com 400 |
| PDF gigante (zip-bomb) esgotando memória na extração | Média | Limite de páginas/caracteres via `importacao.*` (config); falha isolada por documento, não do lote |
| CPF/CNPJ/cartão vazando para a OpenRouter | Alta | `SanitizadorTexto` mascara antes de qualquer chamada; nenhuma exceção do sanitizador alcança o cliente de IA |
| Texto do PDF contendo prompt injection | Média | Delimitadores rígidos no prompt da IA; resposta exigida como JSON estrito (tratado em 05-03) |

<task id="05-02-t2" type="execute" read_first="api/src/main/java/com/controlefinanceiro/common/TenantContext.java api/src/main/java/com/controlefinanceiro/common/ServicoIaIndisponivelException.java">
<action>
Criar `com.controlefinanceiro.importacao.PdfTextoExtractor` (@Component ou classe estática de utilitário, sem Spring se preferível):
- `extrair(byte[] pdfBytes)`: usa `PDFTextStripper` (com `setSortByPosition(true)`), retorna o texto extraído.
- Detectar PDF sem texto extraível: se o texto resultante estiver vazio ou abaixo de um limiar mínimo de caracteres, lançar exceção dedicada `SemTextoExtraivelException` (comum) com mensagem em pt-BR ("PDF sem texto extraível (possivelmente digitalizado)").
- Limites: número máximo de páginas e de caracteres (configuráveis via `importacao.max-paginas`, `importacao.max-caracteres` em `application.yml`); exceder lança `PdfDemasiadoGrandeException`.
- Não persistir o PDF nem o texto bruto.
</action>
<acceptance_criteria>
- `PdfTextoExtractor` existe e compila; gera texto de um PDF de teste (gerar PDF com o próprio PDFBox no teste)
- PDF com zero páginas de texto lança `SemTextoExtraivelException`
- `mvnw -q test -Dtest=PdfTextoExtractorTest` passa (teste unitário sem banco)
- Nenhuma dependência de OCR ou biblioteca de imagem adicionada
</acceptance_criteria>
</task>

<task id="05-02-t3" type="execute" read_first="api/src/main/java/com/controlefinanceiro/common/LinhaInvalidaException.java">
<action>
Criar `com.controlefinanceiro.importacao.SanitizadorTexto` (classe utilitária, testável sem Spring):
- `sanitizar(String texto)`: mascara CPF (`\d{3}\.\d{3}\.\d{3}-\d{2}` → `***.***.***-**`), CNPJ, números de cartão de crédito (sequências de 13–19 dígitos, mantendo apenas os 4 últimos dígitos, ex.: `****-****-****-1234`), agência/conta e outras sequências longas de dígitos (13–19) que não sejam datas isoladas.
- Devolver o texto com dados sensíveis substituídos; nunca falhar por conteúdo estranho (captura `PatternSyntaxException` e devolve o texto original se houver problema).
</action>
<acceptance_criteria>
- `SanitizadorTexto.sanitizar("CPF 123.456.789-00")` → `CPF ***.***.***-**`
- `SanitizadorTexto.sanitizar("cartão 4532015112830366")` → `cartão ************0366` (ou similar, mantendo 4 últimos)
- `mvnw -q test -Dtest=SanitizadorTextoTest` passa
- Nenhum `double`/`float` na classe
</acceptance_criteria>
</task>

<task id="05-02-t4" type="execute" read_first="api/src/main/java/com/controlefinanceiro/lancamento/LancamentoService.java api/src/main/java/com/controlefinanceiro/categoria/Categoria.java">
