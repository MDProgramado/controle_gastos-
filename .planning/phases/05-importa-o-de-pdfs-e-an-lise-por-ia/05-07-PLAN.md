## Threat Model

| Ameaça | Severidade | Mitigação |
|--------|------------|-----------|
| Falha de autenticação/JWT nos novos endpoints | Alta | `security-audit` verificar que `/api/importacoes/**` exige token válido; 401 sem token |
| Exposição de empresa_id no corpo/resposta | Alta | Nenhum DTO de request expõe `empresa_id`; resposta não contém `empresa_id` (gate R3) |
| Endpoint de importação acessível sem token | Alta | SecurityConfig já exige `anyRequest().authenticated()`; novo endpoint entra por padrão |
| Logs vazando header Authorization ou texto sanitizado | Alta | Não logar `Authorization`, cookie `sess` ou texto extraído (seguir ProblemDetailExceptionHandler P7) |
