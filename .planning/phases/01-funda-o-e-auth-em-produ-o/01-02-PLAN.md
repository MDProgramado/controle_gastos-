</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→POST /api/auth/login | credenciais em claro atravessam HTTPS — único ponto que aceita segredo |
| JWT emitido→resource-server | token é o artefato de autorização; qualquer portador vale (Bearer) |
| migration→banco | seed escreve usuário administrador — segredo vem de env var |

| T-2-02 | Tampering | JWT forjado / `alg` downgrade | mitigate | `oauth2ResourceServer` (Nimbus) valida assinatura/`alg`/exp/clock-skew — NÃO hand-roll (Don't Hand-Roll); teste: token aleatório → 401 |
